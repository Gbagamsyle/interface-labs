# Forma

Forma is a planned Interface Labs concept for a creative education experience. The direction is intended to combine learning design, portfolio thinking, and visual storytelling in a way that feels more editorial than conventional LMS tooling.

## Current status

This app is still a scaffold. It is included in the monorepo so the concept can be developed as a standalone product direction with its own identity and structure.

## Intended direction

- Learning journeys with a strong narrative rhythm
- Portfolio and project-based coursework
- Designer-friendly layouts and media-rich teaching modules
- Lightweight and highly visual interface patterns

## Development plan

The application is not yet implemented. The next step is to add the app framework, dependencies, routes, and production scripts when the concept is ready to build.
